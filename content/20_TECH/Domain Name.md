## A. Composition
![[20_TECH-Domain Name.webp|458|333x190]]
>[!note]
> Read the domain name from right to left, since it is more like a `tree structure`.
> [[DNS]] search the domain by this tree structure to find the target.

#### 1. Top-Level Domain
-  where, purpose...
- .com, .edu, .tw
#### 2. Second-Level Domain
- who owns it
- google, github
#### 3. Subdomain
- separate difference services for yourselves
- www(just a custom), api, mail.google.com

---
## B. Administrator
#### 1. Domain Registry
- The instituitions manage top-level domains like [TWNIC](https://twnic.tw/) managing .tw TLD 
#### 2. Domain Registrar
- The platform to sell you second-level domain on different top-level domains.
- Godaddy, Namecheap 
#### 3. Domain Registrant
- User who buys or owns the domain from domain registrar.
