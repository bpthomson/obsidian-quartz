- **Domain Name System**
- Converts human-readable [[Domain Name]] into information stored in [[DNS Record]], such as:
    - IPv4 address (`A`)
    - IPv6 address (`AAAA`)
    - Canonical name (`CNAME`)
    - Mail server (`MX`)
    - Name server (`NS`)
    - Text data (`TXT`)
	> *Those Records are exactly [[DNS Record]]*
- It is a **protocol** or **system** rather than a single physical machine.
- For the actual infrastructure that performs this task, see [[Name Server]].

>[!Tip]
> Just think of DNS as the `phone book system`.
> Matching `shop names`(Domain names) to their respective `Phone Numbers`(A), `Alias`(CNAME), `Mail address`(MX)
