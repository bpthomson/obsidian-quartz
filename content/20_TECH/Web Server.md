## A server that receives HTTP/HTTPS requests from clients and returns HTTP responses. 
> [!Note]
> The returned responses may be `static files` or `dynamic content` generated by a web application.

### For Static files
- Stored in Web server hardware
- HTML, CSS, JavaScript, images, etc...
- Show the static pages to clients

### For dynamic content
- Forward request to [[WSGI Server]] or web applications (Flask, Django), then send back its response to client
- Therefore, requests from the Internet aren't sent directly to backend, and that's the essence of [[Reverse Proxy]].
