- **Uniform Resource Locators**
- Contains several parts

![[20_TECH-URL.webp]]

#### Scheme
- Define the protocol of which the browser must use.
- Protocol defines how to transfer data, like `HTTPS`, `HTTP`(unsecured version of HTTPS).

#### Authority
- Includes [[Domain Name|Domain Name]] and Port.
- If port is not mentioned in url, the defaults are:
	- 80 for HTTP
	- 443 for HTTPS

#### Path to Resource
- the path to the file that puts on the web server

#### Parameters
- for querying, nothing special

#### Anchor
- help website to locate the specified part
	- on HTML, scroll to the part where anchor is defined
	- on video, jump to the timestamp
